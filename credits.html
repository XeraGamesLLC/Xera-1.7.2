About This Site
Made by Juelz, with Claude Pocket Arcade was built for my iPod touch (4th gen, stuck on iOS 6) by me — Juelz — together with Claude, Anthropic's AI. I wanted something that actually loaded right in that ancient copy of Mobile Safari, so everything here is built the way the web actually looked back in 2010: no frameworks, no build step, just HTML, CSS and plain JavaScript a fifteen-year-old browser can run without choking.
Why 2010? Because glossy gradients, drop shadows on everything, and rounded corners on things that didn't need them were peak web design, and this old iPod deserved to feel like it.
Built With
  • Plain HTML, CSS & JavaScript — ES5, no frameworks, no build step
  • A tiny Python web server — serves the site and picks Wordle's word
  • Claude — pair-programmed the whole thing
  • A soft spot for Web 2.0 gradients — no regrets
